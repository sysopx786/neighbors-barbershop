# Neighbors Barbershop

Public site for Neighbors Barbershop, 105 N. Main Street, Spring City, PA.

GitHub Pages serves this branch: https://sysopx786.github.io/neighbors-barbershop/

The shop’s own domain, https://www.theneighborsbarber.com/, is a separate site and is not updated by this repository.

English is the default. Spanish is under `/es/` and Portuguese under `/pt/`.
